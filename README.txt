CROMA LIVE STOCK CHECKER — CHROME EXTENSION

FLOW
1. Croma.com me manually login rakho.
2. Extension me product URL, interval, Telegram Bot Token, Chat ID bharo.
3. Start dabao.
4. Extension real browser tab open karegi.
5. First cycle me product page par Add to Cart click karegi.
6. Cart open karke availability verify karegi.
7. Available milte hi Telegram message bhejegi aur monitoring stop kar degi.
8. Agar unavailable hai to next interval me dubara cart verify karegi.
9. Agar item cart se missing ho gaya to product page par jaake dubara add karegi.

INSTALL
1. ZIP extract karo.
2. Chrome me chrome://extensions kholo.
3. Developer mode ON karo.
4. "Load unpacked" par click karo.
5. Extracted folder select karo.
6. Croma account me login rehna.
7. Extension icon kholo aur settings fill karo.

TELEGRAM SETUP
1. Telegram me @BotFather se bot banao.
2. Bot token copy karo.
3. Apne bot ko ek message bhejo.
4. Chat ID nikalne ke liye:
   https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
5. popup me token/chat ID paste karo.

IMPORTANT
- Ye normal visible browser automation use karta hai.
- Purchase/payment nahi karta.
- Positive stock milte hi Telegram alert karke stop hota hai, spam avoid karne ke liye.
- Croma ka frontend/DOM future me change ho sakta hai; tab content.js selectors adjust karne pad sakte hain.
